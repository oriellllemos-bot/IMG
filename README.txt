# Templates para Classificador de Cartas

Este diretório contém as imagens de template para treinar o classificador de cartas.

## Estrutura de Pastas

- `2/` a `10/`: Cartas numéricas
- `valete/`, `dama/`, `rei/`, `as/`: Cartas de figura

## Como adicionar mais imagens

1. Coloque imagens reais de cartas nas pastas correspondentes
2. Use formatos .png ou .jpg
3. Quanto mais imagens variadas, melhor o treinamento
4. Inclua diferentes ângulos, iluminação e fundos

## Imagens Geradas Automaticamente

Foram geradas imagens sintéticas para teste inicial. 
Para melhor desempenho, substitua por imagens reais de cartas.

## Dicas para coleta de imagens reais

- Capture frames de vídeos de blackjack
- Use diferentes mesas e iluminações
- Inclua cartas parcialmente visíveis
- Varie ângulos e distâncias

## Quantidade recomendada

- Mínimo: 20-30 imagens por valor
- Ideal: 50-100 imagens por valor
- Profissional: 200+ imagens por valor
